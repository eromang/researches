Best model selection: We set metric_for_best_model="accuracy" (instead of defaulting to eval_loss) and bumped save_total_limit from 2 to 3 to prevent the best checkpoint from being pruned before training ends.

We will retrain the model with these changes and publish updated results. We'll also explore further improvements based on the rest of your suggestions (documenting CVE overlap, keyword dependency limitations, etc.)."

### User

and this "We've added focal loss as a new --class-weights focal option (commit f1cd426).

Focal loss (Lin et al., 2017) takes a different approach than class weighting. Instead of uniformly upweighting all minority-class examples, it dynamically reduces the loss contribution of examples the model already classifies confidently and concentrates gradient signal on the hard, uncertain ones. This should help the Low class (where the model struggles) without the brute-force tradeoff that caused Medium recall to drop 11-20pp with class weighting.

The implementation uses gamma=2.0 (standard value) and the balanced class weights as alpha for per-class scaling.

Summary of all modes now available:

Mode    Description
--class-weights none    Uniform loss — clean baseline
--class-weights sqrt    Sqrt-dampened inverse-frequency weights
--class-weights balanced    Full inverse-frequency weights

The pattern is consistent across all weighting strategies: every attempt to boost Low recall cannibalizes Medium. Medium→Low misclassifications jump from ~300 (baseline) to ~2,000 (focal/balanced). Focal loss with balanced alpha was the most aggressive — Medium recall dropped to 64.4%.

This aligns with @eromang's finding that the model relies heavily on keyword/vulnerability-type matching. When a vulnerability has an atypical severity for its type (e.g., High-severity XSS which is typically Medium), accuracy drops to 55.4%. The Low and Medium classes share similar vocabulary in CNVD descriptions, so any rebalancing that pushes the decision boundary toward Low inevitably pulls Medium samples across it.

Conclusion: We're going with the uniform loss baseline (--class-weights none) for the published model.
