# CyberScale Technical Severity v4 (DEPRECATED)

**Status: DEPRECATED for inference in v4.** T-level is now derived deterministically
via `aggregation.derive_t_level()` from impact fields. This model is kept for
reference and backward compatibility testing only.

## Deprecation rationale

The T-level maps deterministically from structured impact fields (service_impact,
data_impact, cascading, affected_entities). The ML model adds no value over the
deterministic rules — it achieves 100% accuracy because the training data labels
are themselves generated by the same deterministic rules.

## v4 field names (changed from v1)

| v1 field | v4 field | v4 values |
|----------|----------|-----------|
| service_disruption | service_impact | none, partial, degraded, unavailable, sustained |
| data_compromise | data_impact | none, accessed, exfiltrated, compromised, systemic |

**v4 input format:** `<description> [SEP] service_impact: <level> entities: <N> sectors: <N> cascading: <level> data_impact: <level>`

## Replacement

Use `cyberscale.aggregation.derive_t_level()` for deterministic T-level:

```python
from cyberscale.aggregation import derive_t_level
t_level, basis = derive_t_level("unavailable", "exfiltrated", "cross_sector", 50)
# t_level = "T3", basis = ["unavailable service impact"]
```
